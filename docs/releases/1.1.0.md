# xcoc 1.1.0

本页记录 1.1.0 的发布准备内容。**截至 2026-10-10，v1.1.0 标签与 GitHub Release 尚未发布；公开最新 Release 仍为 v1.0.0，仅有桌面资产。** 下列名称为当前源码的预期构建输出，实际可下载文件以对应 Release 附件为准。

1.1.0 增加 Android/iOS Release 构建，并将桌面摄像头媒体处理改为内置库工作进程。正式发布使用 `v1.1.0` annotated tag，桌面与移动产物来自同一标签提交。

## Android 与 iOS 发行物

- Android：`xcoc-android-arm64-v8a-unsigned.apk` 与
  `xcoc-android-arm64-v8a-unsigned.aab`，面向 Android 8.0/API 26 及以上的 arm64 设备，
  targetSdk 36。应用版本为 `1.1.0`，versionCode 为 `1001000`。
- iOS 设备：`xcoc-ios-arm64-unsigned.xcarchive.zip` 与 `xcoc-ios-arm64-unsigned.ipa`，
  为 iOS 16 及以上的 arm64 设备归档和标准 Payload 应用包。IPA 来自该归档的同一实机 app。
- iOS 模拟器：`xcoc-ios-simulator-arm64.app.zip`，只用于 arm64 iOS 模拟器。
  iOS marketing version 与 build version 均为 `1.1.0`。
- `xcoc-android-release.json` 和 `xcoc-ios-release.json` 记录版本、准确源码提交、平台、
  Release 配置、未签名状态与文件哈希；发行目录另提供统一的 `SHA256SUMS`。

移动输出为未签名 APK、AAB、IPA、设备归档，以及仅适用于模拟器的 app。实机安装由所有者按[移动端签名说明](../mobile.md#签名后安装或分发)完成稳定签名与分发准备。

CI 与标签发行共用打包步骤，核对产品版本、应用标识、原生库架构、设备/模拟器平台和未签名
状态。正式 Release 仅在所有桌面与移动构建成功后发布；发布脚本拒绝覆盖已存在的 Release。

## 桌面媒体与凭据传输

- 探测、网络摄像头发布和本地录像由同一个 `xcoc` 二进制的独立媒体工作进程执行，通过
  C shim 调用固定版本的 FFmpeg 库。网络摄像头不再依赖外部 `ffmpeg`/`ffprobe` 命令。
- 摄像头 URL/密码、发布 JWT 和私有回环地址通过有界匿名 stdin 管道传递，不进入子进程
  参数、环境变量或临时凭据文件。底层媒体库原始日志被抑制；输入、输出、探测和进程回收
  均有预算或期限。这不隔离本机管理员或拥有进程调试/内存读取权限的账户。
- 发布与录像保留输入音视频轨道，使用码流复制，覆盖 H.264、HEVC 及兼容音频；不支持的
  目标封装组合明确失败。修正多轨 RTSP 发布的流标识/RTP payload type 对应关系，避免
  会话建立成功但接收端无法正确解码的情况。
- 桌面发行静态链接审定的媒体库并提供许可证及重新链接所需源码材料。内置/USB 摄像头仍
  需要带对应设备后端与 `libx264` 的外部 `ffmpeg` 做本地采集；该采集命令不接收网络凭据。
  Android/iOS 使用系统采集和编码，不链接桌面媒体库。

运行前可执行 `xcoc media-worker --check` 检查内置媒体能力。详细的构建、运行依赖及安全
边界见[桌面媒体运行时](../media-worker.md)。

## 移动端修正

- iOS Rust bridge 按当前 ABI v1 校验返回值，新增无需网络的打开、停止、关闭、过期句柄与
  无效输入测试；修正 Xcode 的 Swift 语言模式与构建版本表示。
- Android 在 Android 13/API 33 及以上更新通知前检查通知权限，避免未授权通知更新。
- Release 打包检查拒绝版本漂移、Debug APK、错误 app ID/架构/目标平台，以及混入签名的
  未签名产物；模拟器发行构建与启用 testability 的测试构建分开。

## 版本与数据边界

桌面包、移动 FFI、Android/iOS 应用和安装器的产品版本统一为 `1.1.0`。公共支撑继续固定为
`xcsc 1.0.0`，revision 为 `c45e48e93e360542c2e1db6c6441a9e29b344b03`。摄像头 edge v1、
移动 ABI v1、配置/持久状态及发行清单 schema 的身份独立管理，不随本次软件版本增加。

部署和实机安装按[平台指南](../platform-setup.md)核对程序来源、服务账户、配对状态与权限。移动签名步骤统一见[移动端指南](../mobile.md#签名后安装或分发)。

## 验证边界

Linux 已使用受控合成输入验证内置媒体工作进程、受信任/不受信任 TLS、H.264/HEVC、AAC
与多轨复制、录像分段及凭据不进入命令行。独立 FFmpeg 接收器验证实际收到的数据能够解码；
这些结果不代表真实摄像头型号、生产网络或服务端播放器均已验收。

发布验收以本标签最终提交的完整 CI、各平台构建/测试、发行附件及校验和为准。历史版本的
测试、打包元数据夹具或模拟器运行不能代替 Android/iOS 实机摄像头、权限/生命周期、签名与
分发验收，也不能代替 Windows MSI/SCM、macOS 摄像头权限或 Linux systemd 实际部署测试。
参见[摄像头验证记录](../camera-validation.md)与[当前部署文档](../README.md)。
