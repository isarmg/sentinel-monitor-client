# Sentinel Client 0.3.5

- 升级到 Client Foundation 0.9.13，并固定提交 `995331aa56a9373df0eb090d017532273f00d6ac`。
- 有界 XML 解析改由 Client Foundation 提供，清除对 Foundation Server 的反向依赖；ONVIF 协议及预算仍由 Sentinel 负责。
- Sentinel 继续自行解释配对 HTTP 状态和 `unsupported_client_protocol`；Foundation 只提供产品中立的原生有界终端输入。
- 摄像头、ONVIF、RTSP、MediaMTX 和多实例状态均保持在 Sentinel 产品边界。
