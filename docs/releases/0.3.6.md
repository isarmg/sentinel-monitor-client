# Sentinel Client 0.3.6

- 旧版、损坏或未知的账户/配对状态现在稳定返回 `pairing_state_incompatible`。管理员使用新的授权码显式执行 `setup --replace` 后，Client 会原样归档旧状态，再提交新的配对身份。
- 当前格式中的摄像头配置错误独立返回 `configuration_state_incompatible`，不会被账户恢复流程误删。
- 所有平台都会在运行、状态检查和重新配对前验证本地录像布局。未知目录、链接、非 MP4 文件或不可读内容返回 `important_state_incompatible`，并保留全部录像供兼容版本或管理员处理。
- Windows 原生安装器提供安装目录、旧配置和旧录像保留策略，并通过完成页或失败页明确报告安装结果。
