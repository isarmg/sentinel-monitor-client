# Sentinel Client 0.3.4

- Setup 与摄像头交互配置迁移到 Foundation 0.9.10 的原生控制终端输入；Unix 不再调用 `stty`，Windows 不再启动 PowerShell。
- 授权码与摄像头密码明确提示隐藏输入，并在使用后清零临时缓冲区；所有交互字段都有与产品约束对应的字节上限。
- `setup` 新增 `--timeout-seconds`，默认 300 秒并覆盖完整交互输入序列；取消、超时和终端故障立即返回，不再无限等待。
- 保持唯一的 `sentinel-edge-v3` 协议，不增加旧协议兼容路径。
- 配对 HTTP 错误按入口缺失、方法拒绝、升级要求、授权拒绝和临时不可用分别报告；只有结构化 `unsupported_client_protocol` 才报告协议不兼容，服务器正文和授权码不会写入错误。
